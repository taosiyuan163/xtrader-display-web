2. Data We Collect

We collect the following types of data to provide services, ensure security, and improve product experience.

Data You Provide Directly

A. Contact Information

  • Email Address: Used for account creation, authentication, important notifications
  • Apple Data Type: Contact Info → Email Address
  • Linked to You: Yes | Used for Tracking: No

B. Account Credentials

  • Password: Stored encrypted with hash (we cannot view your original password)
  • Apple Data Type: Sensitive Info (authentication info)
  • Linked to You: Yes | Used for Tracking: No

C. Exchange API Keys 🔐

  • API public and private keys (encrypted storage)
  • Permission scope: Read account, place orders, query positions (authorized by you)
  • Security Measures:
    • AES-256 encrypted storage
    • Only decrypted during trade execution and transmitted via TLS to exchanges
    • We recommend granting only necessary minimal permissions, disable withdrawal permissions
  • Apple Data Type: Sensitive Info → Other Sensitive Info
  • Linked to You: Yes | Used for Tracking: No

Data Collected Automatically

A. Trading & Position Data

  • Order history: Buy/sell orders, price, quantity, timestamp
  • Current positions: Currency, leverage, unrealized PnL
  • Historical returns: Realized PnL, ROI
  • Source: Synced via API from connected exchanges
  • Apple Data Type: Financial Info → Other Financial Info
  • Linked to You: Yes | Used for Tracking: No

Data We Do NOT Collect ❌

To protect your privacy, we explicitly state:

  • Location Data: We do not collect GPS or precise location
  • Contacts/Photos: We do not access your contacts or photo album
  • Browsing History: We do not track browsing behavior outside the app
  • Advertising Identifier (IDFA): We do not use any tracking technology
  • Biometric Raw Data: We do not use Face ID/Touch ID
  • Crash Reporting Services: We do not use third-party crash reporting tools

3. How We Use Data

We only use your data within the following explicit purposes.

Core Service Provision

  • Account Management: Create, verify and manage accounts, authentication
  • Trade Execution: Connect exchanges, execute buy/sell, sync positions & PnL
  • AI Strategy Generation: Send market data to AI models (DeepSeek/Qwen/Claude) to generate trading recommendations
  • Risk Management: Execute stop-loss/take-profit, position limit checks

Involves Data: Email, API keys, strategy configuration, trading data
Legal Basis: Contract performance
